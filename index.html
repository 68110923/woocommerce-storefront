E-commerce Independent Site Frontend

A customizable frontend design system for a WooCommerce / WordPress e-commerce independent site. One continuous gradient canvas, a content-first full-screen hero, and a glass sticky header — all injected as a WordPress mu-plugin, with the theme left untouched.

Features

Everything the storefront needs, in one design system.

CSS/JS split into common / desktop / tablet / mobile. Lightweight — native CSS + a touch of jQuery via IntersectionObserver. No heavy animation library.

🎨

Unified gradient canvas

A single green→purple gradient fills the whole viewport edge-to-edge on every page — no disjointed white blocks.

🎠

Product carousel hero

Content-first homepage: brand tagline + an auto-rotating product carousel spread edge-to-edge, from a [pg_products_carousel] shortcode.

🧊

Glass sticky header

Logo + menu + cart (with live count badge) sit in one flex row, right-aligned, blending into the translucent dark header — then turn solid on scroll.

🛒

Cart drawer

Click the header cart → a side drawer slides in. Adding a product flies it into the cart with a little bump animation.

🗂️

Trust badges & category cards

Glassy trust pills (free over $80, 48h dispatch, full tracking, 4–5 days) and big Shop-by-Category cards with hover motion.

📱

Fully responsive

Desktop / tablet / mobile. On phones the oversized carousel is hidden and core info is shown first — truly mobile-first.

🛡️

18+ age gate

Compliance for the tobacco/vape category: a smooth age-verification modal on first visit, with the choice remembered.

✨

Scroll reveal + toasts

Sections fade/slide in as they enter the viewport (IntersectionObserver). Action feedback via slide-in toasts.

♿

Reduced-motion support

Respects prefers-reduced-motion, disabling most animation for accessibility.

Approach

Content-first homepage (no hidden content).

The homepage is a plain full-screen cover — it scrolls away as one piece, revealing the real store below. Nothing fades out or gets hidden.

Why it works

Entering the site lands you on the core (logo, menu, brand line, featured products). Scrolling brings up trust badges, categories, best sellers, contact and footer — all always visible, never animated away. The hero is a normal 100vh section: simplest, most stable, and nothing gets lost.

Structure

A clean, upgrade-safe layout.

All customization lives in a mu-plugin — the theme and plugins stay untouched, so updates won't break your design.

wp-content/
  mu-plugins/
    shopfront-branding.php      # enqueue assets, shortcode, cart drawer, footer
    shopfront-assets/
      common.css  common.js     # design system, header, buttons, cards, carousel
      desktop.css tablet.css mobile.css   # per-breakpoint tweaks
      desktop.js  tablet.js  mobile.js

Customize

Tune the brand in one place.

Colors and the gradient are CSS variables at the top of common.css.

:root {
  --pg-green:  #16a34a;  --pg-green-d:  #0e7a37;
  --pg-purple: #7c3aed;  --pg-purple-d: #6d28d9;
  --pg-grad: linear-gradient(135deg, #16a34a, #7c3aed);
}
